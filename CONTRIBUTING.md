# Como contribuir

- **Issue:** abra na aba *Issues* para propor um ajuste ou apontar uma lacuna. Diga qual documento, o problema, como verificá-lo e a redação sugerida. Use um exemplo fictício.
- **Fork e pull request:** no GitHub, um fork cria uma cópia de trabalho separada. Faça a alteração nela, em uma branch própria, e abra um pull request para que a sugestão seja revisada. Nada muda aqui até que a contribuição seja aceita.
- **Se usar um agente de IA:** peça um diagnóstico e um diff pequeno. Leia o texto, cheque as fontes e retire informações privadas antes de enviar.

Uma boa contribuição resolve uma dúvida: o que fazer, em que circunstância e como saber se funcionou? Distinga preferência, hipótese, especificação técnica e resultado efetivamente testado. Use referências públicas sem republicar ativos de terceiros.

Não envie dados pessoais, conversas de atendimento, briefs reais, links restritos, métricas internas, arquivos de cliente, credenciais ou materiais sem direito de publicação. Este repositório ainda não declara uma licença de reutilização; visibilidade pública não significa permissão irrestrita para redistribuir.
