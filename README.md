# Azurra · Creative Intelligence for Agents

Base de produção criativa para pessoas e agentes de IA. Reúne guias práticos de direção de arte, motion, edição, áudio e revisão. O objetivo é entregar uma peça clara, fiel ao briefing e fácil de revisar — não apenas gerar uma boa prévia.

## Por onde começar

1. **Antes de produzir:** preencha o [briefing](modelos/BRIEFING.md). Confirme texto, referências, direitos, formatos e quem aprova.
2. **Durante a produção:** siga os guias de [direção de arte](guias/DIRECAO-DE-ARTE.md), [motion, edição e áudio](guias/MOTION-EDICAO-AUDIO.md) e [uso por agentes](guias/USO-POR-AGENTES.md).
3. **Na revisão:** use o [parecer de revisão](modelos/REVISAO.md) e confira os [critérios para conteúdo com IA](guias/ESTUDOS-APLICADOS.md).
4. **No fechamento:** use a [ficha de entrega](modelos/ENTREGA.md) para conferir o export, guardar as fontes editáveis e registrar o que foi enviado.

O briefing vigente, a identidade oficial e a especificação do canal prevalecem sobre qualquer exemplo. Os casos desta edição são fictícios. Os métodos vêm de aprendizados de produção e referências públicas; não são garantias de conversão ou formas de detectar autoria por IA.
