# Ficha de agente e plano de piloto

## Especificação

- **Nome, versão e responsável**
- **Tarefa recorrente e destinatário**
- **Gatilho, entradas obrigatórias e fonte vigente de cada informação**
- **Entrega esperada, destino e critérios de aceite**
- **O que fica fora do papel**
- **Ferramentas, permissões, efeitos externos e confirmação de sucesso**
- **Conflitos, dados ausentes, retomada e ponto de escalonamento**
- **Arquitetura inicial e motivo da escolha**
- **Custo ou quota disponível e caminho para revisão humana**

## Casos de avaliação

| Caso | Entrada e versão | Comportamento esperado | Evidência ou verificação | Resultado observado |
|---|---|---|---|---|
| Tarefa comum | | | | A executar |
| Fonte conflitante ou vencida | | | | A executar |
| Ferramenta indisponível | | | | A executar |
| Ação fora do escopo | | | | A executar |
| Efeito externo com resposta incerta, quando aplicável | | | | A executar |

## Resultado do piloto

- **Configuração de referência e configuração candidata**
- **Tarefas iniciadas, aceitas, bloqueadas e tentativas adicionais**
- **Tempo até aceite, tokens ou quota, custo observável e custo por aceite**
- **Falhas críticas, evidências e testes pendentes**
- **Decisão, responsável e condições para reteste ou reversão**
